Physics, numerical method, and source

This is an original browser implementation of the stadium billiard discussed in Nicholas J. Giordano and Hisao Nakanishi, Computational Physics, second edition, §3.7, “The Billiard Problem,” starting on page 82. See the authors’ table of contents and stadium sample listing. This is an adaptation, not a transcription of their code or a claim to reproduce one specific numbered exercise.

Here R = 1, speed = 1, and y₀ = 0. Vertical straight walls are at x = ±R for |y| ≤ a. Semicircles centered at (0, ±a), with radius R, close the top and bottom. Thus a = 0 gives a circle. The particles do not interact; their visible markers represent mathematical point particles.

Between collisions, r(t + Δt) = r(t) + vΔt. At a wall with outward unit normal n, v′ = v − 2(v · n)n. The program solves ray–line and ray–circle intersections to locate the next collision analytically, then advances both balls to the same physical time. Playback speed changes elapsed simulated time, not collision accuracy. Speed is preserved to floating-point precision.

The position separation shown below is measured at equal times. It can fluctuate and eventually saturates within the finite table; it is not a fitted Lyapunov exponent. The phase-space section uses upward crossings only, an explicitly chosen convention.
